# 羽译 设计大纲

> 状态：M0/M1 已实现，M2–M5 待做。本文件是产品与技术的总纲；工程约定见根目录 `AGENTS.md`，服务商对接细节见 `providers.md`。

## 1. 定位

把「翻译 → 检查 → 润色 → 记住」做成一条线：AI 负责语境与表达，传统机器翻译负责快与便宜，所有修改都以**可读的荧光笔标注**呈现。

差异化（对比划词翻译、沉浸式翻译、沙拉查词）：

| 维度 | 竞品常见做法 | 羽译取舍 |
|---|---|---|
| 多引擎 | 十几个引擎 + 对比 | 沿用「多引擎抽象」，但默认只保留可靠的 AI + 两个免费兜底 |
| 检查/润色 | 另开工具或不做 | 和翻译在同一个面板里做完，修改用荧光笔 diff 展示 |
| 划词 | 词典卡为主 | 默认带上下文（所在段落 + 标题 + 域名）交给 AI 理解 |
| 学习 | 生词本 | 收藏即进复习闭环（SRS），把翻译变成学习入口 |

## 2. 功能大纲

### 2.1 翻译面板（已实现）
- 语言栏：自动检测 → 目标语言，可互换；语言选择持久化。
- 输入：多行文本，`Ctrl+Enter` 翻译；超过 2500 字符按段落自动切段。
- 三动作：翻译 / 检查 / 润色（检查与润色在 M2 实现）。
- 结果：AI 流式输出；显示引擎、耗时、缓存命中、是否降级；复制、清空、历史回看。
- 术语表：设置里维护 `原文 → 译文`，注入提示词。

### 2.2 语法检查（M2）
- 输出结构化 `issues[]`（`start/end/quote/category/severity/explanationZh/suggestion`）+ 终稿。
- 偏移量不可信：模型给 `quote`，前端三级定位（精确 → 去空白 → 失败只进列表）。
- 视图：高亮视图（原文 + 红/黄荧光笔 + 点击展开绿色建议）、列表视图、终稿视图。
- 逐条「采用/忽略」，全部采用有确认，已忽略变灰可恢复。

### 2.3 润色（M2）
- 方向控制两层叠加：
  - 快捷 chips：更自然 / 更正式 / 更口语 / **更诗意** / 更简洁 / 更学术 / 保留术语 / 尽量不改长度。
  - 自由指令框：一句话说清要求（例：「改得像散文，保留全部事实」），直接进提示词。
- 视图：内联合并视图（红底删除线 = 删掉，绿底 = 新增，未动普通字）、并排视图、纯净稿。
- diff 由前端计算（`diff` + `Intl.Segmenter`），模型只给全文与可选说明；长度突变 > 3 倍时护栏提示。
- 「再来一版」：同文本重采样，历史版本可对比。

### 2.4 划词翻译（M3）
- 触发：选中出现小图标（可关）/ `Alt+T` / 右键菜单。
- 气泡：Shadow DOM 挂载、`all: initial` 隔离；译文、源语言、发音、复制、收藏、展开讲解。
- 上下文：选区所在块前后各约 600 字符 + 页面标题 + 域名，缓存键含上下文哈希。
- 单词走词典卡（词性/释义/例句/近义词），句子走直译 + 意译 + 要点。
- 输入框、可编辑区域内不触发。

### 2.5 网页翻译（M4）
- 入口：面板按钮 / 右键菜单 / `Alt+P` / 按域名自动。
- 采集：`TreeWalker` 文本节点，跳过脚本、样式、代码、输入框、`contenteditable`、`[translate="no"]`、隐藏与已译节点。
- 分块：按块级容器聚合成段；纯文本块直接替换，含内联标签先按文本节点分别翻译（占位符保护留到 v2）。
- 呈现：双语对照（原块后插入译文块，`yuyi-*` 命名空间）与仅译文（原文存 `data-yuyi-orig`，可一键还原）。
- 动态内容：`MutationObserver` 防抖 500ms 增量补译；SPA 路由变化重扫。
- 站点规则：`never / auto / manual` + 单站目标语言。
- 性能：`requestIdleCallback` 分片、并发上限（AI 3–5）、`AbortController` 取消、译文缓存。

### 2.6 学习（M5）
1. 生词/短语本：自动带上下文句、来源网址、时间、语言对、标签。
2. 复习：简化 SM-2（`ease` / `interval` / `dueAt`），单次 20 张。
3. 统计：今日新增/待复习、连续天数、正确率。
4. 导入导出 JSON。

待拍板：学习目标是背单词还是积累表达？要不要 AI 例句（花 key）？复习强度？要不要多设备同步？

### 2.7 设置页（已实现骨架）
通用（主题/语言/历史）、翻译引擎（面板与网页翻译各自选引擎）、AI 服务（增删改 + 授权并测试）、免费通道开关、数据与隐私、关于。

## 3. 荧光笔标注规范（M2 的核心）

统一数据结构：

```
Mark = { kind: 'equal'|'del'|'ins'|'warn', text, issueId?, severity?, note? }
```

- 润色：`diff` 算出 `del/ins/equal`。
- 检查：原文为 `equal`，问题片段为 `warn`，紧随其后的绿色片段为 `ins`。
- 颜色语义固定：红 = 错误，黄 = 警告/建议，绿 = 修改后，灰 = 已忽略。
- 不只靠颜色：错误加波浪下划线、已忽略加虚线、`aria-label` 说明。
- 高亮 / 纯净开关；窄栏读不动时用列表视图兜底。

## 4. UI/UX

- 载体：**侧边栏 Side Panel 为主面板**（点图标即开），**设置页 / 生词本为独立标签页**，划词气泡与网页译文注入在页面内。
- 侧栏布局：标题栏（羽译 · 设置齿轮）→ 翻译/历史 tab → 语言栏 → 引擎选择 → 输入区 → 动作行 → 结果卡片 → 底部（翻译本页 · 生词本 · 版本）。
- 设计 token（`src/ui/theme.css`）：主色「羽蓝」`#4C7DFF`；中性灰阶；圆角 8/12/16；间距 4/8/12/16；字体 system-ui + 微软雅黑；深浅色两套变量，跟随系统或手动。
- 交互底线：所有请求有 loading / 失败 / 取消三态；失败文案中文且给「去设置 / 重试」；快捷键在设置页只读展示并指引到扩展快捷键页。

## 5. 技术架构

- Service Worker：唯一联网方；消息路由、右键菜单、快捷键、任务表、缓存、写历史。
- Content Script：页面 DOM 读写（划词/网页翻译），不发网络请求。
- 扩展页面（侧栏/设置/生词本）：React 渲染，直接用 `chrome.storage`。
- 通信：Port 协议（`translate` / `cancel` / `test` → `delta` / `done` / `testDone` / `error`），`requestId` 对齐。
- 构建：一个 `scripts/build.mjs` 连跑三次 Vite（页面多入口、background ESM、content IIFE）。
- 权限：`storage / unlimitedStorage / scripting / activeTab / contextMenus / sidePanel`；`<all_urls>` 内容脚本；自定义 AI 端点走 `optional_host_permissions`。

## 6. 服务商策略

默认链路：**用户 AI Key（主） → 谷歌免费通道 → MyMemory**。国内服务商做成「填了 Key 才亮」的适配器；免费链路只做兜底，并允许一键切走。
实测结论见 `providers.md`。

## 7. 数据与存储

全部 `chrome.storage.local`（v1）：`settings.v1`、`providers` 在 settings 里、`history.v1`（最多 200 条）、`cache.v1`（分片缓存，TTL 7 天）。学习卡片到 M5 再定是否迁 IndexedDB（`storage/learning.ts` 预留一层）。
