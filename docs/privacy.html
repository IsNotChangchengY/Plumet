羽译 PLUMET

隐私政策

版本 1.0.0 · 生效日期 2026 年 11 月 22 日 · 适用于 Chrome 与 Microsoft Edge 上的羽译浏览器扩展

一句话概括

  • 你主动翻译、查词、检查或润色时，相关文本会从浏览器直接发给你选择或配置的翻译 / 词典服务；开发者没有服务器，不中转、不截留这些文本。
  • API Key、设置、历史、生词本与译文缓存只保存在本机（chrome.storage.local），不上传开发者，不跨设备同步。
  • 没有账号体系，没有遥测、统计或广告，不出售、出租或共享你的数据。

1. 这份政策说明什么

羽译（Plumet）是一款浏览器翻译扩展，提供翻译、语法检查、润色与生词学习。本政策说明：哪些数据会离开你的设备、发往哪里；哪些数据只保存在本机；开发者是否收集数据；以及你如何查看和清除这些数据。

本政策适用于本仓库发布的所有羽译扩展版本。本页源码在仓库中公开（docs/privacy.html），修改历史可追溯。

2. 什么情况下会发出文本，发到哪里

只有在你主动操作时，扩展才会把待处理文本发给你选择的服务。具体如下：

  • 划词翻译：选中网页文字后点气泡图标、按 Alt+T 或使用右键菜单时，扩展会发送选中的文字，以及理解语义所需的有限上下文（页面标题、站点域名、所在段落、相邻段落、章节标题等，总预算约 2000 字）。选区超过 2000 字时只带页面标题与站点。
  • 弹窗翻译 / 检查 / 润色：在工具栏弹窗里输入或粘贴文本后点击对应动作，扩展会把该文本发给你在设置中选择的引擎；勾选多个引擎时，每个引擎各收到一份请求。
  • 网页翻译：点「翻译本页」、按 Alt+P 或使用右键菜单时，扩展从当前页面提取可翻译的正文段落并分批发送（每批最多 8 段、1200 字符），跳过代码块、输入框与隐藏内容。网页翻译开始后，页面滚动加载出的新内容会继续按同一任务补译，直到你取消或还原。
  • 查词：划词或输入单个英文词 / 1–4 个汉字时，扩展把该词发往有道词典或 Free Dictionary API 查询；点发音按钮会向同一词典服务下载音频。

免费通道（谷歌翻译、MyMemory）不需要 API Key，但它们同样会把你发送的文本传到对应服务商的服务器，因此与配置了密钥的服务一样受本政策第 3 节约束。

4. 只保存在本机、不会上传的数据

以下数据保存在浏览器的扩展本地存储（chrome.storage.local）中，只有扩展自己能读写：

  • 设置：目标语言、主题、引擎与快捷键、词典展示项等界面偏好。
  • 服务凭证：各服务的 API Key、百度 AppID / 密钥、微软 Key 与区域、自定义端点的地址与 Key。它们只会在请求对应服务时随该请求发送，开发者无法看到。
  • 翻译历史：你在弹窗「历史」里看到的本地记录。
  • 生词本：收藏的卡片、词典快照、SM-2 复习进度与统计。
  • 缓存：译文缓存（主缓存最多 1000 条、段落缓存最多 3000 条，7 天滑动过期）与查词缓存（最多 200 条，24 小时滑动过期），用于减少重复请求与计费。

这些数据不上传到开发者的服务器，也不跨设备同步（扩展没有使用 chrome.storage.sync）。你可以随时在设置里清空缓存、在历史里删除记录、在生词本里删除卡片，或卸载扩展；卸载后浏览器会删除扩展的本地存储。

5. 开发者不做什么

  • 没有自建服务器或中转服务。扩展的所有网络请求都由浏览器直接发往你选择的服务商。
  • 不收集遥测。没有使用统计、崩溃上报、埋点或任何分析 / 广告 SDK。
  • 不出售、出租或共享你的数据。除第 3 节列出的、你主动选择的服务商外，没有其他接收方。
  • 不建立账号。不要求登录，不收集姓名、邮箱、手机号或设备标识。
  • 不读取与你的操作无关的网页内容。内容脚本在网页加载后只注册划词与快捷键监听；只有你划词或发起翻译时才会读取页面文本，网页翻译写回的译文节点在还原时会被移除。

6. 扩展申请了哪些权限，为什么

权限用途
storage、unlimitedStorage在本机保存设置、历史、生词本与译文 / 词典缓存；缓存可能超过扩展默认存储配额，所以申请无限存储。
contextMenus网页右键菜单里的「翻译选中内容」与「翻译此页」。
内容脚本（<all_urls>，含 iframe）在网页里显示划词气泡、隐藏内容守卫态与网页翻译结果；只在你的操作触发时读取文本。

可选主机权限（https://*/*、http://localhost/*、http://127.0.0.1/*）添加自定义 OpenAI 兼容服务时，在你点击「授权并测试」后才按需申请，用于访问你指定的端点。

扩展没有申请 tabs、activeTab、scripting、webRequest、cookies 等额外权限，也没有声明任何远程托管代码。

7. 安全

  • 与内置服务商之间的通信使用 HTTPS。
  • 如果你为自定义端点填写了 HTTP 地址（例如本机服务），该段通信的安全性取决于你的端点；请只添加你信任的服务。
  • 凭证以明文形式保存在浏览器为扩展隔离的本地存储中。能访问你这套浏览器用户目录的程序、或共用这台设备的人，可能读到这些数据；请保护好设备与浏览器账户，并建议使用额度有限、可随时吊销的 API Key。

8. 数据保留与删除

  • 本机数据保留到你主动删除或卸载扩展；缓存会按有效期自动过期。
  • 一键清空译文与词典缓存：设置 →「清空译文与词典缓存」；历史与生词本可逐条删除；卸载扩展会删除全部本地数据。
  • 已经发往第三方服务商的数据由各服务商按其政策保留或删除。开发者无法访问、也不会代为删除这些数据，如有需要请直接联系对应服务商。

9. 儿童

羽译不面向儿童定向设计，也不收集年龄信息。若未成年人使用本扩展，请在监护人指导下进行。

10. 政策更新

当扩展的数据处理方式发生变化时，我们会更新本页并修改开头的生效日期；重要变化会在仓库的 Release 说明中提示。更新后继续使用扩展即表示接受更新后的政策。

English summary

Plumet (羽译) is a browser extension for translation, grammar checking, polishing and vocabulary learning. This policy explains what leaves your device:

  • Only when you explicitly trigger an action (translate a selection, translate a page, check or polish text, or look up a word), the relevant text — plus limited context such as the page title, site domain and nearby paragraphs for selections — is sent directly from your browser to the translation or dictionary provider you selected or configured: Google Translate (free channel), MyMemory, Baidu, Microsoft Azure Translator, OpenAI, Google Gemini, xAI, DeepSeek, SiliconFlow, Moonshot, Zhipu AI, Alibaba DashScope, Youdao Dictionary, Free Dictionary API, or a custom OpenAI-compatible endpoint you add. Each provider processes data under its own privacy policy.
  • API keys, settings, translation history, vocabulary cards and translation/dictionary caches are stored only locally in chrome.storage.local. They are not uploaded to the developer, not synced across devices, and are deleted when you clear them or uninstall the extension.
  • The developer runs no server, collects no telemetry or analytics, requires no account, and does not sell, rent or share your data.
  • The extension requests storage, unlimitedStorage, contextMenus, content-script and host permissions for the built-in providers, and optional host permissions for the custom endpoints you authorize. It does not request tabs, activeTab, scripting, webRequest or cookies.
