# 01 · 加载与调试

## 1. 第一次跑起来

```powershell
cd D:\Project\Plumet
pnpm install
pnpm build
```

打开 Edge，地址栏输入 `edge://extensions`：

1. 左下角打开「开发人员模式」。
2. 点「加载解压缩的扩展」。
3. 选择 `D:\Project\Plumet\dist`（注意是 dist，不是项目根目录）。
4. 列表里出现「羽译」，工具栏出现蓝色「羽」图标。
5. 点图标 → 图标下方弹出羽译翻译窗口；检查、润色、历史都在这个窗口里。

如果点了没反应，先看「羽译」卡片上有没有红色的错误按钮。

## 2. 各处的日志去哪看

| 想看什么 | 在哪看 |
|---|---|
| Service Worker 报错 / `console.log` | 扩展卡片上的「Service Worker」→ 点「检查」 |
| 弹窗报错 | 在弹窗里右键 →「检查」 |
| 设置页报错 | 设置页上右键 →「检查」 |
| content script 报错 | 打开任意网页 → F12 → Console（content script 的日志会出现在页面的 console 里） |
| 存了什么数据 | 在弹窗或设置页的 Console 里执行 `await chrome.storage.local.get(null)` |

## 3. 改完代码怎么生效

代码改了**不会自动生效**，因为浏览器加载的是 `dist/`，不是源码：

```powershell
pnpm build          # 重新生成 dist
```

然后回 `edge://extensions`，点「羽译」卡片上的刷新按钮（圆形箭头），再关掉弹窗重开。

想省一次手动 build 就开 `pnpm dev`，它会在文件变化时自动重建；但**刷新扩展的那一步还是要手动点**。

## 4. 快捷键

- `Alt+T` 翻译选中内容
- `Alt+P` 翻译当前页面
- 改键：`edge://extensions/shortcuts`

## 5. 验证当前功能（五分钟）

1. 点图标，在弹窗里输入 `Hello world, this is a translation test.`，按 `Enter`。
2. 应该看到「谷歌翻译（免费通道）」给出中文，结果卡片里显示引擎与耗时。
3. 回 `edge://extensions` 刷新扩展，再点图标重开弹窗 → 再翻一句 → 切到「历史」tab 能看到刚才两条。
4. 打开设置页 → 加一个 AI 服务（填 DeepSeek 的 Base URL、模型、Key）→ 点「授权并测试」→ 浏览器弹权限框点「允许」→ 应显示连接成功与示例译文。
5. 把弹窗里的引擎切到刚加的 AI 服务，再翻译一次 → 这次由 AI 输出。
6. 把 Key 改错再试 → 应看到「API Key 无效或没有权限（HTTP 401）」这类中文提示，而不是白屏。
7. 在弹窗输入框粘一段有错的英文（例：`I has a apple. She dont like it.`）→ 点「检查」→ 原文里错误处红底划掉、黄色表示建议，绿色紧跟改法；点某条「忽略」后那片变灰虚线；「终稿」里替换正确。
8. 回到同一个输入框，展开「润色方向」勾「更诗意」并写「写给中学生看」→ 点「润色」→ 合并视图里删除是红色划线、新增是绿底；切「纯净稿」复制；点「再来一版」再跑一次。
9. 随便打开一个英文网页，选中一句话 → 文字旁出现「译」小图标 → 点开气泡，应看到译文、引擎与耗时，按钮可朗读/复制；滚动页面气泡会跟着选区走；按 `Esc` 关闭。
10. 在网页的搜索框/评论框里选中文字 → 不应出现图标（输入区域被排除）；回设置页把「划词翻译 → 触发方式」改成「只用快捷键」，再在网页选中文字 → 图标不出现，但按 `Alt+T` 或右键菜单「羽译：翻译选中内容」仍能弹气泡。
11. 打开一个英文网页（维基百科条目、MDN 文档都行）→ 点图标打开弹窗 → 底部点「翻译本页」→ 弹窗自动关闭，正文每段下面出现中文，代码块与输入框不动，页面布局不塌；页面右下角状态条显示「已译 N 段 · 引擎」。
12. 回设置页把「网页翻译 → 呈现方式」改成「仅译文」→ 回到网页，重开弹窗再点一次「翻译本页」→ 原文被译文取代（代码块与图片还在）；点右下角「还原本页」→ 页面回到英文原样，DOM 里不再有 `data-yuyi` 节点。
13. 另开一个很长、可以无限滚动的英文页面 → 用弹窗点「翻译本页」，快完成时点页面右下角状态条的「取消」→ 已译部分保留、不再继续请求；刷新后重翻同一页 → 应该很快完成（缓存命中）；滚动出新内容 → 半秒后自动出现译文。

## 6. 调试小抄

- 弹窗一直转圈：多半是 SW 被回收或 fetch 失败，打开 SW 检查器看报错。
- 报「无法连接到扩展后台」：扩展刷新过，旧弹窗的 Port 失效，关掉弹窗重开。
- 「翻译本页」没反应或提示当前页面用不了：`edge://`、扩展商店、PDF 内置查看器禁止注入 content script；普通网页则是扩展刚好刷新过，刷新页面再试。
- 网页翻译的日志在页面 Console 里（content script 的 `console` 与页面共用）；SW 那边看 Network 面板。
- 网页翻译错位/翻错段：先看状态条是不是「N 段失败」，失败段落会带橙色虚线框；点「重试失败」即可，不用整页重翻。
- 免费通道偶尔失败：本地网络有 MITM 代理，偶发 502/504，重试一次即可。
- 想看请求发到哪：SW 检查器 → Network 面板。
