# 01 · 加载与调试

## 1. 第一次跑起来

```powershell
cd D:\Project\Plumet
pnpm install
pnpm build
```

打开 Edge，地址栏输入 `edge://extensions`：

1. 左下角打开「开发人员模式」。
2. 点「加载解压缩的扩展」。
3. 选择 `D:\Project\Plumet\dist`（注意是 dist，不是项目根目录）。
4. 列表里出现「羽译」，工具栏出现蓝色「羽」图标。
5. 点图标 → 右侧弹出羽译面板。

如果点了没反应，先看「羽译」卡片上有没有红色的错误按钮。

## 2. 各处的日志去哪看

| 想看什么 | 在哪看 |
|---|---|
| Service Worker 报错 / `console.log` | 扩展卡片上的「Service Worker」→ 点「检查」 |
| 侧栏页面报错 | 在侧栏上右键 →「检查」 |
| 设置页报错 | 设置页上右键 →「检查」 |
| content script 报错 | 打开任意网页 → F12 → Console（content script 的日志会出现在页面的 console 里） |
| 存了什么数据 | 在侧栏或设置页的 Console 里执行 `await chrome.storage.local.get(null)` |

## 3. 改完代码怎么生效

代码改了**不会自动生效**，因为浏览器加载的是 `dist/`，不是源码：

```powershell
pnpm build          # 重新生成 dist
```

然后回 `edge://extensions`，点「羽译」卡片上的刷新按钮（圆形箭头），再关掉侧栏重新打开。

想省一次手动 build 就开 `pnpm dev`，它会在文件变化时自动重建；但**刷新扩展的那一步还是要手动点**。

## 4. 快捷键

- `Alt+T` 翻译选中内容（M3 实现后生效）
- `Alt+P` 翻译当前页面（M4 实现后生效）
- 改键：`edge://extensions/shortcuts`

## 5. 验证 M1 功能（三分钟）

1. 侧栏里输入 `Hello world, this is a translation test.`，点「翻译」。
2. 应该看到「谷歌翻译（免费通道）」流式/整段给出中文，右侧显示耗时。
3. 回 `edge://extensions` 刷新扩展，再打开侧栏 → 历史 tab 里能看到刚才这条。
4. 打开设置页 → 加一个 AI 服务（填 DeepSeek 的 Base URL、模型、Key）→ 点「授权并测试」→ 浏览器弹权限框点「允许」→ 应显示连接成功与示例译文。
5. 把「翻译面板」的引擎切到刚加的 AI 服务，回侧栏再翻译一次 → 这次由 AI 输出。
6. 把 Key 改错再试 → 应看到「API Key 无效或没有权限（HTTP 401）」这类中文提示，而不是白屏。

## 6. 调试小抄

- 面板一直转圈：多半是 SW 被回收或 fetch 失败，打开 SW 检查器看报错。
- 报「无法连接到扩展后台」：扩展刷新过，旧面板的 Port 失效，关掉侧栏重开。
- 免费通道偶尔失败：本地网络有 MITM 代理，偶发 502/504，重试一次即可。
- 想看请求发到哪：SW 检查器 → Network 面板。
