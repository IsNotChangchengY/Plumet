## 2. 一次翻译的完整旅程

```
侧栏 TranslatePanel.submit()
  └─ splitSegments(text)                      // 长文切段
  └─ useTranslateJob.run()                    // 生成 requestId，Port 发 translate
        ↓
Service Worker: chrome.runtime.onConnect     // background/index.ts
  └─ handleJobMessage()                      // background/jobs.ts
  └─ loadSettings()                          // storage/settings.ts
  └─ translateWithFallback(settings, engine) // core/engine.ts
        ├─ makeCacheKey → getCached          // core/cache.ts
        ├─ resolveEngine(engineId)           // core/providers/registry.ts
        │     └─ createAiProvider / createGoogleFreeProvider / createMyMemoryProvider
        │           └─ fetchWithTimeout → ensureOk → 解析
        └─ 失败则按 fallbackEngineIds 换免费通道再试
  └─ 每次 onDelta → port.postMessage({kind:'delta'})
  └─ 成功 → postMessage({kind:'done'}) + addHistory()
        ↓
侧栏 useTranslateJob.onMessage → setState → 界面渲染
```

几个设计点：

- **requestId 是唯一线索**：面板生成，SW 原样带回；面板只认自己当前的 requestId，避免旧请求串台。
- **降级不污染流式**：只有主引擎收到的 delta 会推送；降级后的结果以 `done` 整体覆盖。
- **缓存在 SW 里**：面板关闭后 SW 可能被回收，但缓存对象已经落盘到 `storage.local`。

## 3. 设置是怎么存的

- 结构定义在 `src/storage/settings.ts`（`Settings` 类型 + `DEFAULT_SETTINGS`）。
- 任何页面 `loadSettings()` 都拿到补齐默认值后的完整对象（`normalizeSettings`）。
- 设置页每次改动都调 `patchSettings()` 写回；输入框有 400ms 防抖（`options/App.tsx`）。
- 面板只改语言与引擎，也是同一个 `patchSettings`。

## 4. 历史

`src/storage/history.ts`：一个数组放 `history.v1`，最新在前，最多 200 条，单条文本截断到 4000 字符。历史开关关掉后 `addHistory` 直接跳过。

## 5. 后面的里程碑长在哪

- **M2 检查/润色**：`src/core/providers/ai/` 加 `check.ts`、`polish.ts` 的提示词与 JSON 校验；`src/app/marks/` 加 Mark 模型与 `<DiffText>`；`TranslatePanel` 把「检查/润色」按钮接上。
- **M3 划词**：`src/content/selection.ts` + `bubble.ts`（Shadow DOM 气泡），SW 复用现有 translate 任务；新增 `context` 字段从 content script 传上去。
- **M4 网页翻译**：`src/content/page/` 四个文件（采集/分块/写回/观察器），面板加进度条与控制按钮。
- **M5 学习**：`src/storage/learning.ts` + `src/learning/` 页面；收藏入口加在气泡和面板结果区。

## 6. 为什么这样分层

- `core/` 里没有 `chrome.*` 之外的浏览器依赖，也没有 React —— 这样能被单测直接跑（`tests/` 里的 29 个测试全是 core 层）。
- `storage/` 是唯一碰 `chrome.storage` 的地方，且在测试环境里会退化到内存 Map（`storage/local.ts`）。
- `app/` 与 `sidepanel/` 分开，是为了以后设置页也能复用同一个翻译面板组件。
