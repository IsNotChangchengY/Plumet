# 03 · 常见错误对照

## 加载扩展时

| 现象 | 原因 | 解决 |
|---|---|---|
| `edge://extensions` 报「清单文件缺失或不可读取」 | 选错了目录（选了项目根而不是 `dist`），或还没 build | `pnpm build` 后重新选 `D:\Project\Plumet\dist` |
| 报 `Could not load icon 'icons/16.png'` | 图标缺失或 manifest 路径写错 | 确认 `dist/icons/{16,32,48,128}.png` 存在；图标源文件在 `assets/icon-master.png` |
| 报 `Manifest is not valid JSON` | 直接手改了 `public/manifest.json` 少写逗号 | 用 JSON 校验器检查；`pnpm verify` 也会查引用 |
| 报 `Service worker registration failed` | background 打包成了 IIFE 或引用了 DOM | 检查 `scripts/build.mjs` 里 background 用的是 `formats:['es']` |

## 运行时

| 现象 | 原因 | 解决 |
|---|---|---|
| 点图标没反应 | SW 崩溃导致 `setPanelBehavior` 没设上；或 Edge 版本低于 114 | 看 SW 检查器报错；确认 `edge://version` 的版本 |
| 侧栏显示「与后台的连接中断了，请再点一次翻译」 | 扩展刷新过，旧 Port 失效 | 关掉侧栏重新打开 |
| 侧栏显示「无法连接到扩展后台」 | SW 起不来（构建坏了/被浏览器停用） | 看 SW 检查器；重新 build + 刷新扩展 |
| 一直「正在翻译…」不动 | 网络卡住或服务不响应（超时 90 秒） | 等超时或点「停止」；看 SW 的 Network |
| 「网络请求失败」 | 断网、服务地址错、或该地址没授权 | 先用「谷歌翻译（免费通道）」验证网络；自定义 AI 服务点过「授权并测试」吗 |
| 「API Key 无效或没有权限（HTTP 401）」 | Key 错了 / 过期 / 没开通该模型 | 去设置页重填；确认模型名存在 |
| 「接口地址不对（HTTP 404）」 | Base URL 少了 `/v1` 或多了斜杠 | 例：`https://api.deepseek.com/v1` |
| 「请求过于频繁或额度不足（HTTP 429）」 | 免费通道限流 / AI 余额不足 | 换引擎或稍后重试；MyMemory 免费额度约 5000 字符/天 |
| 「AI 返回的 JSON 结构不对」 | 模型没按格式输出，或批量段数不一致 | 重试；换更稳的模型（如 deepseek-chat） |
| 检查报「AI 返回的 JSON 里缺少 issues 数组」 | 模型输出了解释文字而不是 JSON | 已自动修复重试一次；仍失败就换个模型或缩短文本 |
| 检查结果里显示「N 条未能定位」 | 模型给的 `quote` 与原文不完全一致（改字/加空格/漏字） | 正常现象：这些条目不参与划线；换更稳的模型能减少它 |
| 检查/润色报「还没有可用的 AI 服务」 | 这两条链路只能用 AI，且还没配 | 设置页 → AI 服务 → 添加并「授权并测试」；或在「翻译引擎」里把检查/润色指定到某个 AI 服务 |
| 润色报「AI 没有返回润色结果」 | 模型输出了空内容或被内容过滤 | 重试或换模型；长文可先缩短 |
| 侧栏很窄时「并排」是灰的 | 并排需要 560px 以上的宽度 | 拉宽侧栏或用「合并 / 纯净稿」视图 |
| 选中文字后没有出现「译」图标 | 触发方式被设为「只用快捷键」或「关闭」；或者选中的是输入框 / contenteditable 里的文字 | 设置页 → 划词翻译 → 改回「选中后显示小图标」；输入框里本来就不触发 |
| 划词气泡打不开或一直转圈 | content script 没注入（浏览器内置页、扩展商店页、PDF 查看器）；或扩展刷新过导致旧脚本失效 | 换普通网页试；刷新页面；看页面 Console 有没有报错 |
| 划词报「与扩展后台的连接中断了」 | 扩展重载过，页面里的旧 content script 已失效 | 刷新页面后再选 |
| 气泡挡住文字或贴到屏幕边缘 | 选区太靠页面顶部/底部，会自动翻到另一侧并贴边收进视口 | 正常行为；`Esc` 关闭后换一段再选 |
| 同一个词在不同页面翻译不一样 | 划词会把「页面标题 + 网站 + 所在段落」作为语境一起发出去 | 这是设计行为：语境不同，译法本来就该不同 |
| 在网页译文上选中文字没有「译」图标 | 译文是我们自己写入的节点（`data-yuyi`），划词会主动忽略 | 正常；想查原句就选中原文那一段 |
| 点「翻译本页」没反应，或按钮是灰的 | content script 没注入（浏览器内置页、扩展商店、PDF 内置查看器），或扩展刚刷新过 | 换普通网页；刷新页面后再试 |
| 网页翻译到一半停住、只译了一部分 | 某一批请求失败（网络抖动、免费通道限流），失败段落带橙色虚线框 | 点页面右下角状态条的「重试失败」；或「还原本页」后重来 |
| 网页翻译出现原文和译文一样的两行 | 目标语言是英/法/德这类拉丁语系，无法靠书写系统判断「已经是目标语言」 | 换目标语言；完全相同的文本已经自动去重，不会重复插入 |
| 代码块、输入框、隐藏段落没有被翻译 | 设计如此：这些内容不参与采集 | 正常 |
| 滚动出来的新内容没有自动补译 | 点了「取消」、达到 400 段上限，或内容在 iframe 里 | 刷新后重翻；iframe 内暂不支持 |
| 「还原本页」后页面还是译文 | 页面脚本自己改写了我们写入的节点，还原只处理自己插入的部分 | 刷新页面 |
| 网页翻译报「请求过于频繁或额度不足」 | 免费通道限流；或 AI 余额不足 | 稍后重试，或在设置页把「网页翻译」换成另一个引擎 |
| 设置页点「授权并测试」没弹权限框 | 不是用户手势触发，或地址模式非法 | 直接在按钮点击回调里调用；地址必须是 `http(s)` 开头 |
| 面板语言/引擎改了没保存 | 侧栏关闭太快，写入还没完成 | 等半秒再关；或到设置页改 |

## 开发与构建

| 现象 | 原因 | 解决 |
|---|---|---|
| 改了代码页面没变 | 没重新 build / 没刷新扩展 | `pnpm build` → `edge://extensions` 点刷新 → 重开面板 |
| `pnpm build` 报 `manualChunks is not a function` | Vite 8（Rolldown）不接受对象写法 | 已用函数形式；别改回对象 |
| `content.js` 加载报 `Cannot use import statement outside a module` | content 被打成了 ESM | 保持 `formats:['iife']` |
| `pnpm test` 报 `UNABLE_TO_GET_ISSUER_CERT_LOCALLY` | 本机网络是 MITM 代理，Node 不信任它的证书 | `$env:NODE_OPTIONS='--use-system-ca'` 再跑；浏览器不受影响 |
| 联网测试报 `Cross-Origin Request Blocked` | happy-dom 会做 CORS 拦截 | 测试文件首行加 `// @vitest-environment node` |
| 联网测试全部 skip | 需要显式打开开关 | `$env:YUYI_LIVE='1'` |
| `pnpm install` 很慢或失败 | 网络抖动（本机链路偶发 502/504） | 重试；必要时换 registry 镜像 |
| `tsc` 报 `noUnusedLocals` | 有没用的变量/导入 | 删掉；这是刻意开的严格项 |

## 尚属正常的情况

- 生词本页面只有说明文字 —— 在 M5。
- 在某些页面（`edge://`、扩展商店、PDF 内置查看器）划词与网页翻译无效 —— 浏览器禁止扩展注入这些页面。
- 网页译文是纯文本：段落里的链接、加粗没有跟着翻 —— 占位符保护留到后续版本。
- 已经翻成目标语言的段落不再重复翻（按书写系统判断），所以中文页面选「翻译本页」可能提示「没有需要翻译的段落」—— 正常。
- iframe 里的内容不会被翻译 —— 内容脚本目前只跑在主框架。
- 按域名自动翻译还没做 —— 目前需要手动点「翻译本页」或用 `Alt+P`。
